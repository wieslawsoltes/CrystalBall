# CrystalBall

Aether Orb hardware, firmware, manufacturing engineering and browser digital prototype.

The initial import is preserving the supplied Rev A files byte-for-byte. Each original file is checked against its SHA-256 manifest before the baseline import is committed. Subsequent engineering changes are separate commits on `main`.

**Release status: engineering development; not approved for production manufacture.** Physical verification and manufacturing sign-off are mandatory and will not be represented as completed by software-only checks.
